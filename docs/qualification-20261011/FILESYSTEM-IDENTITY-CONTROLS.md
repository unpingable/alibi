# Open filesystem identity controls

Declared by root before execution, after independent G35 review requested real
GNU df correspondence for spaces and bind views. These are supplemental controls,
not hidden holdouts and not an expansion of the diagnostic inventory.

FS01 mounts a healthy actual ext4 loop filesystem at a pathname containing two
consecutive spaces; a real write/read, statfs, exact GNU df byte/inode rows and
mountinfo independently establish identity and capacity. FS02 adds a read-only
bind view while verifying the backing mount remains writable. FS03 removes the
exact loop and bind mounts, detaches the loop, and checks the restored tmpfs root.
For each, sufficient complete evidence permits and warrants bounded silent-killer
CLEAR. No filesystem pathology is claimed. Inadequate acquisition warrants UNKNOWN
but must be distinguished from useful exoneration when the oracle proves adequate
inputs existed. The same archive/tools are used by an ordinary external CLI.

Original G35 negative proof and these healthy controls test different propositions.

replacement history. Root owns these small inputs; logs/receipts retained through
